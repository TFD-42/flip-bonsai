# Project Status

**Current status:** Experimental / early hobby development

**Last significant activity:** 2026-08-13 (initial port)

## What this means

This is a personal hobby project — a Flipper Zero port of the
[cbonsai](https://gitlab.com/jallbrit/cbonsai) growth algorithm. It's
functional (grow a new random tree, view it, regrow) but young: expect
rough edges, and features may change without much ceremony. Issues and PRs
are welcome and will be looked at, but there's no formal release cadence.
